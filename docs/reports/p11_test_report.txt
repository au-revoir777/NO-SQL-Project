## Acceptance criteria
- Unit test: validity check on a hand-built LR with a known closed-form counterfactual
  (test_counterfactual_is_the_closed_form_and_flips_the_decision); stability metric is 0 for zero
  perturbation (test_zero_perturbation_is_perfectly_stable).
- The what-if endpoint returns exactly the scorer's output for the unmodified vector
  (test_unmodified_vector_returns_exactly_the_scorer_output: equal to scorer.predict on the stored vector
  and to the alert's recorded risk); a counterfactual applied through it flips the decision.
- Distributions reported (median, IQR, counts), not selected examples: docs/research/e12_tables.md.
- results/e12_explanations/: collection from commit eef051e (clean), 50 runs, stream digests equal to E10's.
- Semi-global view: generated as an E12 table (mean |contribution| per ring type). The Experiments page
  that would show it is P8, not built yet.
