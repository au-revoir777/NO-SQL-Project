  every active user of the course graph x k = 1..3 x caps (250,20), (10,3), (2,2), (1,1), compared

  neighbourhoods for every user and two attribute seeds, filters): tests/test_integration_explorer.py,
  run by the CI integration job (Neo4j 5.26); skipped on this laptop, where it is deliberately not run
  against the local Neo4j because the test wipes the database.

## Fixed while testing
- The neighbourhood canvas stayed empty: Cytoscape loads asynchronously and the elements were added
  before it existed. The canvas now redraws once Cytoscape is ready, and Playwright checks that the
  canvas has drawn pixels (the table-based checks had not caught it).
- axe: the Ctrl K hint and the highlighted palette option's secondary text were below 4.5:1.
- The Cypher transfers query scanned every transaction per user; it now uses an indexed UNION.
  Memory search now lists active users only, and Neo4j existence requires a linked user, as in memory.

## Notes
- Times in the explorer are simulated epoch seconds shown in UTC; the course graph has all links at
  the start of the simulated day, so its time filter has little to cut.
- The node table is collapsed by default (the graph has a text summary and the table on demand).
