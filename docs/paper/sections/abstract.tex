\begin{abstract}
Rule-based fraud-ring detectors hide busy shared attributes behind a degree
cap; learned graph models are more accurate but brittle. We study a streaming
pipeline that keeps hub links as pairwise evidence, and add a graph neural
network whose member probabilities feed the ring scorer. A label-free shift
guard watches the share of users the GNN flags and falls back to the
evidence-based scorer when that share leaves its reference range. On a
simulator, with protocols committed before each run and fresh test seeds,
this pipeline (AnchorPipe) beats the strongest existing method, GraphSAGE, by
\AnTOneVsgnnunscoredD{} F1 in distribution (95\% CI \AnTOneVsgnnunscoredLo{} to
\AnTOneVsgnnunscoredHi{}). When benign and ring amounts overlap, GraphSAGE
collapses and the unguarded GNN pipeline falls to \AnTTwosagepipeF{}, while
AnchorPipe stays level with the rule-based pipeline (\AnTTwoanchorF{} against
\AnTTwoproposedF{}). Inside the pipeline, a degree cap costs \RfCapD{} F1. All
data are synthetic.
\end{abstract}
